description: Debug sistematis
---

Gunakan skill `superpowers systematic-debugging` untuk debugging berbasis akar masalah.

Masalah: $ARGUMENTS

Ikuti proses 4 fase:
1. Investigasi: kumpulkan bukti, jangan menebak.
2. Temukan akar masalah.
3. Perbaiki dengan satu perubahan terfokus.
4. Verifikasi dengan verification-before-completion.

Jangan mengubah kode sebelum akar masalah ditemukan.
