---
description: Otomasi browser (agent-browser)
---

Gunakan skill + tool `agent-browser` untuk otomasi browser.

Instruksi: $ARGUMENTS

Gunakan perintah CLI agent-browser (open, snapshot, click, fill, screenshot, network) atau tool MCP agent-browser untuk:
- Membuka website / navigasi
- Screenshot / snapshot
- Mengklik, mengisi form, menguji alur
- Memeriksa request/network
